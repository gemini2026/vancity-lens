INTEGRATION SUMMARY
===================

To integrate into main.py:

1. Add imports at top:
   from .metrics import PrometheusMiddleware, get_metrics
   from .metrics_routes import router as metrics_router

2. Add middleware (after MaxPageSizeMiddleware):
   app.add_middleware(PrometheusMiddleware)

3. Add router (after auth_router):
   app.include_router(metrics_router)


METRICS OVERVIEW
================

HTTP Request Metrics:
- request_duration_seconds: Histogram with p50/p95/p99 buckets
- api_calls_total: Counter by method/endpoint/status
- active_requests: Gauge for concurrent requests
- errors_total: Counter for error responses

Infrastructure Metrics:
- db_pool_size: Connection pool state (active/idle/total)
- cache_hit_ratio: Cache effectiveness (0.0-1.0)
- cache_hits_total: Total cache hits
- cache_misses_total: Total cache misses


EXCLUDED ENDPOINTS
==================

These endpoints are excluded from metrics:
- /health (liveness check)
- /ready (readiness check)
- /metrics (metrics endpoint itself)

Customizable via PrometheusMiddleware.EXCLUDED_PATHS

ALERT THRESHOLDS
================

All configurable in /config/prometheus/alert_rules.yml:

HighLatencyP95: P95 > 5 seconds (5 min warning)
HighLatencyP99: P99 > 10 seconds (3 min critical)
HighErrorRate: Error rate > 5% (2 min warning)
CriticalErrorRate: Error rate > 10% (1 min critical)
DBPoolExhaustion: Pool > 90% utilized (2 min critical)
LowCacheHitRatio: Hit ratio < 50% (10 min info)
HighConcurrentRequests: > 100 active (5 min warning)

TROUBLESHOOTING QUICK REFERENCE
================================

/metrics endpoint 404:
  → Check metrics_routes.py is imported
  → Verify router is included in main.py

No data in Prometheus:
  → curl http://localhost:8000/metrics (verify endpoint)
  → Check Prometheus targets page
  → Verify prometheus.yml config

High cardinality warnings:
  → Monitor unique endpoint values
  → Consider grouping dynamic paths

Alerts not firing:
  → Verify alert_rules.yml is loaded
  → Check Prometheus Alerts page
  → Verify thresholds and durations

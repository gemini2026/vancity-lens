DATABASE SCHEMA
================================================================================

subscription_tiers (4 rows seeded)
  - id (PK)
  - name (UNIQUE)
  - display_name
  - price_monthly, price_annual
  - max_watchlists, max_api_calls_daily, max_signals_per_query
  - features (JSONB)
  - is_active
  - created_at

user_subscriptions (dynamic)
  - id (PK)
  - user_id (UNIQUE FK) → users
  - tier_id (FK) → subscription_tiers
  - status (active/cancelled/expired/trial)
  - trial_ends_at, current_period_start, current_period_end
  - cancel_at_period_end
  - created_at, updated_at

usage_tracking (daily accumulation)
  - id (PK)
  - user_id, usage_date (UNIQUE composite)
  - api_calls, signals_queried, chat_messages, exports
  - created_at

================================================================================
CORE METHODS (SubscriptionManager)
================================================================================

TIER OPERATIONS
  - get_tiers() → List[TierInfo]
  - get_tier(tier_name) → TierInfo | None

SUBSCRIPTION OPERATIONS
  - get_user_subscription(user_id) → UserSubscription | None
  - create_subscription(user_id, tier_name, trial_days=14) → UserSubscription
  - upgrade_subscription(user_id, new_tier) → UserSubscription
  - downgrade_subscription(user_id, new_tier) → UserSubscription
  - cancel_subscription(user_id) → UserSubscription
  - reactivate_subscription(user_id) → UserSubscription

USAGE TRACKING
  - track_usage(user_id, usage_type, count=1) → None
  - check_limit(user_id, limit_type) → bool
  - get_usage(user_id, date=None) → UsageStats
  - get_usage_summary(user_id, days=30) → Dict

DEPENDENCIES
  - require_tier(min_tier) → dependency factory
  - check_rate_limit(limit_type) → dependency factory

INTEGRATION STEPS
================================================================================

1. Run database migration:
   psql $DATABASE_URL < db/019_subscriptions.sql

2. Add routers to FastAPI app (api/main.py):
   from api.subscription_routes import router, admin_router
   app.include_router(router)
   app.include_router(admin_router)

3. Update user registration to create default subscription:
   await SubscriptionManager.create_subscription(db_pool, user_id, "free", 14)

4. Add tier requirements to protected endpoints:
   @app.post("/api/v1/protected")
   async def protected(
       user: Dict = Depends(get_current_user(db_pool)),
       _: None = Depends(require_tier("starter")(db_pool)),
       db_pool: asyncpg.Pool = None,
   ):

5. Add rate limit checks to API endpoints:
   _: None = Depends(check_rate_limit("api_calls")(db_pool)),

6. Track usage after operations:
   await SubscriptionManager.track_usage(db_pool, user["id"], "api_calls", 1)

7. Run tests:
   pytest tests/test_subscriptions.py -v

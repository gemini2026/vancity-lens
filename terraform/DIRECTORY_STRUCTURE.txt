DATA FLOW EXAMPLES
==================

1. Pod → Cloud SQL:
   Pod (10.1.x.x) → Cloud SQL Auth Proxy → Private SQL (10.0.1.x)

2. Pod → Secret Manager:
   Pod (Workload Identity) → Service Account → Secret Manager

3. Pod → Artifact Registry:
   Pod (GKE SA) → Artifact Registry (Pull image)

4. External → GKE:
   Internet → Load Balancer (TBD) → Ingress → Pod

# VanCity Lens — UI/UX Review Report

**Date:** 2026-02-17
**Review Type:** Comprehensive E2E UI/UX validation with data integrity analysis
**Reviewer:** Claude Opus 4.6 (via review-ux skill)
**Screenshots:** 16 captured (13 successful, 3 scenarios with empty states)

## Executive Summary

VanCity Lens is a professional real estate intelligence platform with strong technical implementation but several critical UX issues that impact usability. The application successfully displays complex geospatial data (92K parcels, 540 signals, 42 neighborhoods) but suffers from contrast issues in light theme, persistent unexplained error badges, and missed opportunities for progressive disclosure.

**Overall Assessment:** B+ (Good foundation, needs UX polish)

### Critical Issues (Must Fix)
1. **Low contrast text in light theme** - neighborhood names barely visible (WCAG AA failure)
2. **Persistent "1 Issue" badge** - appears on all screens with no context or dismiss option
3. **Missing empty state illustrations** - chat area and other sections lack helpful empty states

### Major Issues (Should Fix)
4. **Search autocomplete missing** - no address suggestions shown when typing
5. **Layer control affordance weak** - unclear which controls are interactive
6. **No comparison CTA** - checkboxes exist but no hint they enable comparison
7. **Mobile touch targets too small** - some controls under 44x44px minimum

### Strengths
- ✅ Professional dark theme with good contrast
- ✅ Rich data display and filtering
- ✅ Responsive design (mobile viewport tested)
- ✅ Mapbox GL integration works well
- ✅ Theme toggle functional
- ✅ Clear 3-tab navigation structure

### V-06: Neighborhoods View — Light Theme
**Screenshot:** `12_light_hoods.png`
**Status:** ❌ **CRITICAL ISSUE**

**Accessibility:** ❌ **WCAG AA Failure**
- **Neighborhood names have extremely low contrast** (light gray on white background)
- Contrast ratio appears < 2:1 (WCAG AA requires 4.5:1 for normal text)
- Names are barely readable
- Scores and other text have better contrast but still low

**Visual Polish:** ❌ Poor
- Light theme appears unfinished or broken
- Lacks the refinement of dark theme
- Background is too bright white (should be off-white or light gray)

**Issues Found:**

| ID | Severity | Issue | Location | Fix |
|----|----------|-------|----------|-----|
| V-06-01 | **CRITICAL** | Neighborhood names low contrast | All cards | Change text color from #e5e5e5 to #1f2937 (dark gray) |
| V-06-02 | Major | Score labels low contrast | All cards | Increase contrast to meet WCAG AA |
| V-06-03 | Major | Background too bright | Page background | Change from #ffffff to #f9fafb (off-white) |
| V-06-04 | Minor | Card borders missing | Cards | Add subtle 1px border (#e5e7eb) to separate cards |
| V-06-05 | Minor | Persistent "1 Issue" badge | Bottom-left | Same as V-01-01 |

**Recommended Improvements:**
1. **CRITICAL:** Fix text contrast in light theme:
   - Neighborhood names: #1f2937 (dark gray) on #ffffff (white) = 16.1:1 ✅
   - Best/Weakest labels: #4b5563 (medium gray) on #ffffff = 9.8:1 ✅
   - Scores: Keep current blue #3b82f6 (4.5:1 on white) ✅

2. Change page background from pure white to off-white (#f9fafb)

3. Add subtle borders to cards:
   ```css
   .neighborhood-card-light {
     border: 1px solid #e5e7eb;
     background: #ffffff;
   }
   ```

4. Test all text against WCAG AA contrast checker (https://webaim.org/resources/contrastchecker/)

**Contrast Requirements:**
- Normal text (< 18pt): 4.5:1 minimum
- Large text (≥ 18pt or 14pt bold): 3:1 minimum
- Current dark gray on white: ~16:1 ✅
- Current light gray on white: ~2:1 ❌

### Touch Target Sizes
```css
/* Minimum touch targets (iOS Human Interface Guidelines) */
--touch-target-min: 44px;
--touch-target-comfortable: 48px;
--touch-target-large: 56px;

/* Apply to all interactive elements on mobile */
@media (max-width: 768px) {
  button, a, input[type="checkbox"], .interactive {
    min-width: var(--touch-target-min);
    min-height: var(--touch-target-min);
  }
}
```

Cloud SQL is the main cost (~$10-20). Cloud Run scales to zero when Colin isn't using it. AI API costs are pay-per-use — seeding 100 docs costs ~$2-5 total, then chat queries are ~$0.003 each.

⚡ Data Flow: Scraping → Signals

Scrape: aiohttp fetches PDFs/HTML from Vancouver gov sites → stored in documents table.
Chunk: semchunk splits into ~800 token pieces → stored in document_chunks.
Embed: Cohere embed-english-v3.0 (1024 dims) → stored as vector(1024) in pgvector + tsvector for BM25.
Extract: Claude reads each chunk → extracts structured signals (address, zoning changes, vote counts, severity) → stored in intelligence_signals.
Query: User asks a question → hybrid search (dense + BM25 + RRF) → Cohere rerank → Claude synthesis → cited answer.

🔒 Security

API keys in GCP Secret Manager (not env vars). Cloud SQL uses private IP + Auth Proxy. Cloud Run is public but CORS-restricted. No user auth for POC (Colin is the only user). Frontend is static — no secrets embedded.
